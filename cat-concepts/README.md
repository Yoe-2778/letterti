# 双猫主题视觉方向

这组参考用于「恋爱来信」现有网页的双猫背景与互动插画选型，暂未改动主测试页面。

| 编号 | 文件 | 方向 | 用途 |
| --- | --- | --- | --- |
| 01 | `01-line-art.png` | 手绘来信 | 轻量主插画、页角线稿、双猫印章 |
| 02 | `02-storybook.png` | 温柔绘本 | 柔和背景、日常关系场景、结果页插画 |
| 03 | `03-soft-clay.png` | 奶油小窝 | 立体主视觉、角色互动、分享卡片 |

每张方向板包含上方双猫主视觉和下方四种互动：靠近、递信、保留空间、依偎陪伴。现阶段是视觉概念板，尚未拆分成透明素材。

浏览器打开 `/cat-concepts.html` 可切换风格，比较首页应用示意和完整元素板。

生成方式：codex-image2 技能原生 CLI；模型 `gpt-image-2`；尺寸 `1536x1024`。03 为 `high` 质量，01/02 为响应错误后以 `medium` 质量重试的结果。完整英文提示词保存在同目录 `prompts.jsonl`，实际重试参数保存在 `retry-prompts.jsonl`。`*-hero.png` 为从方向板裁切的首页预览素材。

后续选定方向后，再统一角色特征，制作可直接用于网页的独立资源。
